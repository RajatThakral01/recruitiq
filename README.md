# RecruitIQ — AI-Powered Resume Screener

> Screen resumes in seconds, not hours. RecruitIQ uses AI to score, rank, and explain every candidate against a job description.

---

## What is RecruitIQ?

RecruitIQ is an intelligent resume screening platform that automates the most time-consuming part of hiring. Upload a job description and up to 10 resumes — RecruitIQ uses large language models to parse, score, and rank every candidate with detailed insights on strengths and gaps.

It works for **any role type** — engineering, marketing, sales, operations, finance, and more.

---

## Features

- **AI-Powered Scoring** — each resume is evaluated across 5 dimensions: skills match, ATS optimization, project quality, experience relevance, and education
- **Ranked Results** — candidates are sorted by final score with a Strong Fit / Moderate Fit / Not Fit recommendation
- **Key Strengths & Gaps** — specific, evidence-based insights generated by the LLM for every candidate
- **ATS Keyword Analysis** — matched and missing keywords highlighted for each resume
- **Runtime Provider Switching** — switch between Mistral and Groq LLM providers from the UI without restarting
- **Multiple JD Input Modes** — upload a PDF or paste the job description as text
- **Batch Resume Upload** — upload up to 10 PDF resumes at once
- **Fully Dockerised** — runs with a single command, no manual setup needed

## Scoring System

Each resume is scored across 5 dimensions and combined into a weighted final score:

| Dimension | Weight | Method |
|---|---|---|
| Skills Match | 30% | LLM evaluation with transferable skill recognition |
| Experience Relevance | 25% | LLM evaluation with domain match and seniority alignment |
| Project Quality | 20% | LLM evaluation of impact, complexity, and ownership |
| ATS Optimization | 15% | Keyword matching with fuzzy search and synonym mapping |
| Education | 10% | Education level vs JD requirement |

**Scoring Modes** (set via `SCORING_MODE` in `.env`):

| Mode | Behaviour |
|---|---|
| `llm_first` | LLM scores used directly, algorithmic as fallback only (recommended) |
| `hybrid` | 65% LLM + 35% algorithmic blend |
| `legacy` | Algorithmic scoring only, no LLM |

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/health` | Health check for API and database |
| POST | `/api/upload/jd` | Upload a job description PDF or TXT |
| POST | `/api/upload/resumes` | Upload up to 10 resume PDFs |
| POST | `/api/screen` | Run the full screening pipeline |
| GET | `/api/results/{job_id}` | Get ranked results for a screening job |
| GET | `/api/results/{job_id}/candidate/{resume_id}` | Get detailed profile for one candidate |
| POST | `/api/config/provider` | Switch LLM provider at runtime |

## Getting Started

### Prerequisites

- Docker and Docker Compose installed
- A Mistral API key from [console.mistral.ai](https://console.mistral.ai) and/or a Groq API key from [console.groq.com](https://console.groq.com)

### Run with Docker (recommended)
```bash
# 1. Clone the repo
git clone https://github.com/RajatThakral01/recruitiq.git
cd recruitiq

# 2. Set up environment variables
cp .env.example .env
# Edit .env and add your API keys

# 3. Start the app
docker-compose up --build

# 4. Open in browser
http://localhost:8000
```

### Run locally (without Docker)
```bash
# 1. Create virtual environment
python -m venv .venv
source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# 3. Set up environment variables
cp .env.example .env
# Edit .env and add your API keys and DATABASE_URL

# 4. Start the app
python -m src.main
```

## Environment Variables

Copy `.env.example` to `.env` and fill in your values:
```bash
# Database
DATABASE_URL=postgresql://recruitiq:recruitiq@localhost:5432/recruitiq

# LLM Configuration
LLM_PROVIDER=mistral          # mistral or groq
SCORING_MODE=llm_first        # llm_first, hybrid, or legacy

# API Keys (add at least one)
MISTRAL_API_KEY=your_mistral_api_key_here
GROQ_API_KEY=your_groq_api_key_here

# LLM Settings
LLM_TIMEOUT_SECONDS=90.0
LLM_MAX_RETRIES=3
MISTRAL_MODEL=mistral-large-latest
GROQ_MODEL=llama-3.3-70b-versatile

# App Settings
MAX_FILE_SIZE_MB=10
MAX_RESUMES=10
CORS_ORIGINS=*
LOG_LEVEL=INFO
```

## How It Works
Upload JD + Resumes
↓
Extract text from PDFs (pdfplumber)
↓
Parse JD structure with LLM
↓
Parse each resume with LLM
↓
Run parallel LLM scoring (skills + projects + experience)
↓
Run ATS keyword scoring
↓
Compute weighted final score
↓
Generate strengths & gaps with LLM
↓
Rank and return results
